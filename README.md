# Agentic RAG Copilot — Prototype

Hybrid retrieval over sample inventory with cited answers; deterministic, no external LLM.

**Status:** demo/prototype, not production ready. Uses public-free or synthetic sample content, never customer data.

## Run

```powershell
cd 01-agentic-rag-copilot
python -m pip install -r requirements.txt
python app.py
```

See `app.py` for implementation. A successful local run is needed before publishing.
